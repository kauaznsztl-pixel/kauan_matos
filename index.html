PROJETO 01 EM DESENVOLVIMENTO

INTER26 — Interclasse 2026

Organização de um campeonato esportivo escolar, acompanhada da criação de uma plataforma digital para gerenciar e acompanhar as competições.

O que envolve

Planejamento de modalidades como futsal e vôlei, equipes, tabelas, sorteios, confrontos, distribuição dos jogos e premiações.

Plataforma digital

Consulta de jogos e resultados, classificação, mata-mata, estatísticas de atletas e equipes, artilharia, assistências, favoritos, galeria de fotos e painel administrativo.

PROJETO 02 DESENVOLVIMENTO INICIAL

Craque Manager

Jogo de gerenciamento de futebol para PC, inspirado em simuladores do gênero. A proposta é permitir que o jogador construa sua própria carreira no futebol, escolha clubes, gerencie equipes e tome decisões dentro do universo do jogo.

Proposta e recursos planejados

Banco de jogadores baseado em atletas reais, escolha entre clubes existentes ou personalizados e um universo com diversos clubes.

Partidas em 2D com câmera superior (Top View), velocidade ajustável, diferentes formas de controle e modo para um jogador.

Desenvolvimento

Projeto desenvolvido no Visual Studio Code com HTML, CSS e JavaScript. Há planejamento de integração com APIs de futebol para obter dados de jogadores e clubes.

HTMLCSSJavaScriptAPIs · planejadas

Estrutura visual, tela inicial e primeiros fluxos de escolha de clube já trabalhados. As mecânicas principais ainda serão desenvolvidas.
